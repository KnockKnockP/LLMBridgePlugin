# PriorArt.compact

Comparable UE LLM/editor bridge products/projects: VibeUE: in-editor chat + external MCP + Blueprint services/graph construction, https://www.vibeue.com/ . UE-MCP: TypeScript MCP server + C++ Unreal editor bridge over JSON-RPC/WebSocket; Blueprint graph scripting/compile/undo; UE5.4-5.7, https://ue-mcp.com/ . Blueprint Stack: UE5.4+ editor plugin with Codex/Claude integrations, HTTP JSON-RPC MCP, Blueprint editing tools, https://www.noglyphstudio.com/blueprintstack/docs . CreateLex: commercial AI Blueprint generator for prompt-to-function/wiring, https://createlex.com/ .

UE APIs used/related: `FHttpServerModule/IHttpRouter/FHttpServerRequest/FHttpServerResponse` local HTTP server, https://dev.epicgames.com/documentation/tr-tr/unreal-engine/API/Runtime/HttpServer . Blueprint editor graph APIs: `FBlueprintEditorUtils::CreateFunctionGraph`; node spawner APIs: `UBlueprintAssetNodeSpawner::Create`, https://dev.epicgames.com/documentation/en-us/unreal-engine/API/Editor/UnrealEd/Kismet2/FBlueprintEditorUtils/CreateFunctionGraph and https://dev.epicgames.com/documentation/en-us/unreal-engine/API/Editor/BlueprintGraph/UBlueprintAssetNodeSpawner/Create . Remote Control HTTP exists but targets exposed object properties/functions, not arbitrary Blueprint graph authoring, https://dev.epicgames.com/documentation/en-us/unreal-engine/remote-control-api-http-reference-for-unreal-engine .

Conclusion: existing pattern = local editor bridge + external agent protocol. This plugin = small/auditable C++ editor bridge with JSON tool discovery and Blueprint-specific mutation tools.
